## **Before Opening an Issue**

Before submitting a technical ticket in a repository:

1. **Review the Core Documentation**: Check the `README.md` and any `docs/`.
2. **Search Existing Trackers**: Query open and closed issues on both [GitHub][gh] and [GitLab][gl] to verify whether the behavior is already tracked.
3. **Sanitize All Logs**: Strip all tokens, certificates, internal hostnames, and personal identifiers before pasting stack traces or diagnostic output.
